# Edu Nexus I18n and Theme

- Add user-facing copy to both EN and VI locale files.
- Register new namespaces in `app/shared/lib/i18n/resources.ts`.
- Use semantic Tailwind token classes.
- Add new colors in `app/styles/theme.css`.
- Do not hard-code hex colors or palette utilities in components.
