# Development Workflow

1. Search existing code and read nearby patterns first.
2. Read `AGENTS.md` before code changes.
3. Keep changes small and inside the correct layer.
4. Preserve user changes.
5. Review your own diff.
6. Verify with `npm run typecheck`, `npm run lint`, or `npm run build` as appropriate.

Do not install packages or commit unless the user asks.
