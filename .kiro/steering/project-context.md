# Edu Nexus Project Context

- Frontend web app for Edu Nexus, an education/learning platform.
- React Router 7 SSR, React 19, TypeScript strict, Vite 8, Tailwind CSS v4 CSS-first.
- i18n uses Vietnamese by default and supports English.
- Theme supports dark/light mode through CSS variables in `app/styles/theme.css`.
- Mock API uses MSW + Faker; Orval is ready when BE provides Swagger.
- `AGENTS.md` is the source of truth.
